# ONE ASCEND – App

Gebaute Web-App (PWA) von ONE ASCEND, Stand `38926e7`.
Alle persönlichen Daten bleiben lokal im Browser des Geräts; die App sendet keine Einträge an Server.
Netzwerk nur für das Laden der App (dieser Hoster) und – abschaltbar – Kartenkacheln von OpenFreeMap bzw.
OpenStreetMap (Anbieter sieht IP-Adresse und Kartenausschnitt).

iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
